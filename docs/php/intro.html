核心知识点

1. PHP 简介​

1.1 什么是 PHP？​

PHP (Hypertext Preprocessor) 是一种广泛使用的开源通用脚本语言，特别适用于 Web 开发并可嵌入 HTML 中。它的语法吸收了 C、Java 和 Perl 的特点，易于学习，使用广泛。PHP 主要在服务器端执行，用于生成动态网页内容。

1.2 PHP 的特点​

  • 服务器端脚本语言: 代码在服务器上执行，客户端（浏览器）只接收结果（通常是 HTML）。
  • 嵌入式: 可以直接嵌入到 HTML 代码中。
  • 跨平台: 可以在多种操作系统上运行（Windows, Linux, macOS 等）。
  • 广泛的数据库支持: 支持几乎所有主流数据库（MySQL, PostgreSQL, SQLite, Oracle, SQL Server 等）。
  • 开源免费: 拥有庞大的社区支持和丰富的文档资源。
  • 弱类型语言: 变量类型通常不需要显式声明，PHP 会根据上下文自动转换（但也支持类型声明 Type Hinting）。

2. 基本语法​

2.1 PHP 标记​

PHP 代码需要写在特定的标记之间，最常用的是 <?php ... ?>。

<!DOCTYPE html>
<html>
<head>
    <title>PHP Basic Syntax</title>
</head>
<body>
    <h1>
        <?php
            echo "Hello from PHP!"; // PHP code block
        ?>
    </h1>
    <p>This is standard HTML.</p>
    <?php
        // Another PHP block
        $message = "This message is generated by PHP.";
        echo "<p>" . $message . "</p>";
    ?>
    <?="<p>Short echo tag example.</p>"?> <!-- Short echo tag (requires short_open_tag=On or PHP 5.4+) -->
</body>
</html>

2.2 注释​

  • 单行注释: // 或 #
  • 多行注释: /* ... */
<?php
// This is a single-line comment

# This is also a single-line comment

/*
This is a
multi-line comment block.
It can span multiple lines.
*/

$name = "Alice"; // Comment after code
?>

2.3 输出内容​

使用 echo 或 print 语句向浏览器输出内容。echo 通常稍快一些，且可以一次输出多个参数。

<?php
$greeting = "Hello";
$target = "World";

echo $greeting;          // Output: Hello
echo "<br>";             // Output HTML line break
echo $greeting, " ", $target, "!"; // Output multiple arguments: Hello World!
echo "<br>";

print $greeting . " " . $target . " (using print)!"; // Output using print: Hello World (using print)!
print "<br>";

$result = print "Print returns 1."; // print returns 1
echo "<br>";
echo "Print returned: " . $result; // Output: Print returned: 1
// echo does not have a meaningful return value like print
?>

3. 变量与数据类型​

3.1 变量​

  • 以 $ 符号开头，后跟变量名。
  • 变量名区分大小写。
  • 变量名必须以字母或下划线开头。
  • 变量在使用前不需要声明，赋值即创建。
<?php
$firstName = "Bob"; // String
$age = 30;          // Integer
$price = 19.99;     // Float (Double)
$isActive = true;   // Boolean
$_system_status = "OK"; // Variable starting with underscore

echo $firstName; // Output: Bob
echo "<br>";
echo $Age; // Notice: Undefined variable: Age - demonstrates case sensitivity

$firstName = "Charlie"; // Variable value can be changed
echo $firstName; // Output: Charlie
?>

3.2 数据类型​

PHP 支持多种数据类型：

  • 标量类型 (Scalar Types):
    • string: 字符串 (文本)
    • int (或 integer): 整数
    • float (或 double): 浮点数
    • bool (或 boolean): 布尔值 (true 或 false)
  • 复合类型 (Compound Types):
    • array: 数组 (有序映射)
    • object: 对象 (类的实例)
    • callable: 可调用类型 (函数或方法)
  • 特殊类型 (Special Types):
    • null: 表示变量没有值
    • resource: 特殊变量，表示外部资源 (如数据库连接、文件句柄)
<?php
$str = "This is a string";
$count = 100;
$pi = 3.14159;
$isEnabled = false;
$scores = [95, 88, 72]; // Array (short syntax)
$person = (object) ['name' => 'David', 'city' => 'London']; // Simple object cast
$noValue = NULL;

var_dump($str);       // string(18) "This is a string"
echo "<br>";
var_dump($count);     // int(100)
echo "<br>";
var_dump($pi);        // float(3.14159)
echo "<br>";
var_dump($isEnabled); // bool(false)
echo "<br>";
var_dump($scores);    // array(3) { [0]=> int(95) [1]=> int(88) [2]=> int(72) }
echo "<br>";
var_dump($person);    // object(stdClass)#1 (2) { ["name"]=> string(5) "David" ["city"]=> string(6) "London" }
echo "<br>";
var_dump($noValue);   // NULL
echo "<br>";

// Resource example (won't show much with var_dump alone without context)
// $fileHandle = fopen("myfile.txt", "r");
// var_dump($fileHandle); // resource(id#...) of type (stream)
// if ($fileHandle) fclose($fileHandle);
?>

3.3 类型转换 (Type Casting/Juggling)​

PHP 会根据上下文自动转换类型（Type Juggling），也可以显式转换（Type Casting）。

<?php
$numString = "50";
$numInt = 10;

// Implicit conversion (juggling) during arithmetic operation
$sum = $numString + $numInt; // $numString is treated as integer 50
echo "Sum (implicit): " . $sum . " (Type: " . gettype($sum) . ")"; // Sum (implicit): 60 (Type: integer)
echo "<br>";

// Explicit conversion (casting)
$castedInt = (int) $numString;
$sumExplicit = $castedInt + $numInt;
echo "Sum (explicit): " . $sumExplicit . " (Type: " . gettype($sumExplicit) . ")"; // Sum (explicit): 60 (Type: integer)
echo "<br>";

$floatVal = 9.81;
$castedToInt = (int) $floatVal; // Cast float to int (truncates decimal)
echo "Casted float to int: " . $castedToInt; // Casted float to int: 9
echo "<br>";

$boolVal = (bool) ""; // Empty string casts to false
var_dump($boolVal); // bool(false)
echo "<br>";
$boolVal = (bool) "0"; // String "0" casts to false
var_dump($boolVal); // bool(false)
echo "<br>";
$boolVal = (bool) "Hello"; // Non-empty string casts to true
var_dump($boolVal); // bool(true)
?>

3.4 常量 (Constants)​

使用 define() 函数或 const 关键字定义常量。常量一旦定义，其值不能改变，且默认是全局作用域。常量名通常全大写。const 关键字用于类常量和全局常量（PHP 5.3+），define() 只能定义全局常量。

<?php
// Using define() - can be used anywhere
define("SITE_NAME", "My Awesome Website");
define("MAX_USERS", 100);
// define("SITE_NAME", "Another Name"); // Error: Constant SITE_NAME already defined

echo SITE_NAME; // Output: My Awesome Website
echo "<br>";
echo MAX_USERS; // Output: 100
echo "<br>";

// Using const - outside classes, usable only at top-level scope or inside classes (PHP 5.3+)
const APP_VERSION = "1.2.0";
echo APP_VERSION; // Output: 1.2.0
echo "<br>";

// const cannot be defined conditionally like define()
/*
if (true) {
    const CONDITIONAL_CONST = "Yes"; // Fatal error: const declarations cannot be conditional
}
*/
if (true) {
    define("CONDITIONAL_DEFINE", "Yes"); // OK
    echo CONDITIONAL_DEFINE; // Output: Yes
}
?>

4. 运算符 (Operators)​

4.1 算术运算符​

+ (加), - (减), * (乘), / (除), % (取模), ** (幂 - PHP 5.6+)。

<?php
$a = 10;
$b = 3;
echo $a + $b; // 13
echo "<br>";
echo $a % $b; // 1
echo "<br>";
echo 2 ** 4; // 16
?>

4.2 赋值运算符​

= (赋值), +=, -=, *=, /=, %=, **=, .= (字符串连接赋值)。

<?php
$x = 5;
$x += 3; // $x is now 8
echo $x;
echo "<br>";

$message = "Hello";
$message .= " World!"; // $message is now "Hello World!"
echo $message;
?>

4.3 比较运算符​

== (等于, 值比较), === (全等, 值和类型比较), != 或 <> (不等于), !== (不全等), <, >, <=, >=。 太空船运算符 <=> (PHP 7+)：用于比较两个表达式。当 $a 小于、等于或大于 $b 时，它分别返回 -1、0 或 1。

<?php
$val1 = 10;
$val2 = "10";

var_dump($val1 == $val2);  // bool(true) - loose comparison (type juggling)
echo "<br>";
var_dump($val1 === $val2); // bool(false) - strict comparison (different types)
echo "<br>";
var_dump($val1 != $val2);  // bool(false)
echo "<br>";
var_dump($val1 !== $val2); // bool(true)
echo "<br>";

// Spaceship Operator (PHP 7+)
$x = 5;
$y = 10;
echo ($x <=> $y); // -1 ($x < $y)
echo "<br>";
echo ($y <=> $x); // 1 ($y > $x)
echo "<br>";
echo ($x <=> 5);  // 0 ($x == 5)
?>

4.4 逻辑运算符​

&& 或 and (逻辑与), || 或 or (逻辑或), ! (逻辑非), xor (逻辑异或)。 (&& 和 || 优先级高于 and 和 or)

<?php
$isLoggedIn = true;
$isAdmin = false;

var_dump($isLoggedIn && $isAdmin); // bool(false)
echo "<br>";
var_dump($isLoggedIn || $isAdmin); // bool(true)
echo "<br>";
var_dump(!$isAdmin);              // bool(true)
?>

4.5 递增/递减运算符​

++$var (前置递增), $var++ (后置递增), --$var (前置递减), $var-- (后置递减)。

<?php
$counter = 5;
echo ++$counter; // 6 (increment then return)
echo "<br>";
echo $counter;   // 6
echo "<br>";

$counter = 5;
echo $counter++; // 5 (return then increment)
echo "<br>";
echo $counter;   // 6
?>

4.6 错误控制运算符 (@)​

抑制错误消息的显示。强烈不推荐滥用，应使用适当的错误处理机制。

<?php
// Without @, this would likely cause a Notice: Undefined variable: nonExistentVar
$value = @$nonExistentVar;
echo "Value is: ";
var_dump($value); // Value is: NULL

// Better approach: check if variable exists
if (isset($anotherNonExistentVar)) {
    $value = $anotherNonExistentVar;
} else {
    $value = "default";
}
echo "Value (checked): " . $value; // Value (checked): default
?>

4.7 三元运算符与 Null 合并运算符​

  • 三元运算符: condition ? value_if_true : value_if_false
  • Null 合并运算符 (?? - PHP 7+): value1 ?? value2 - 如果 value1 存在且不为 NULL，则返回 value1，否则返回 value2。常用于替代 isset() ? ... : ...。
  • Null 合并赋值运算符 (??= - PHP 7.4+): $var ??= default - 如果 $var 不存在或为 NULL，则将其赋值为 default。
<?php
// Ternary Operator
$age = 20;
$status = ($age >= 18) ? "Adult" : "Minor";
echo "Status: " . $status; // Status: Adult
echo "<br>";

// Null Coalescing Operator (PHP 7+)
$username = $_GET['user'] ?? 'guest'; // If $_GET['user'] is not set or is NULL, use 'guest'
echo "Username: " . $username; // Assuming $_GET['user'] is not set, output: Username: guest
echo "<br>";

// Equivalent using ternary and isset()
$usernameOld = isset($_GET['user']) ? $_GET['user'] : 'guest';
echo "Username (old way): " . $usernameOld;
echo "<br>";

// Null Coalescing Assignment Operator (PHP 7.4+)
$options['color'] ??= 'blue'; // If $options['color'] is not set or is null, set it to 'blue'
$options['size'] = 'large';
$options['size'] ??= 'medium'; // 'size' is already set, so it remains 'large'

var_dump($options); // array(2) { ["color"]=> string(4) "blue" ["size"]=> string(5) "large" }
?>

5. 控制结构​

5.1 条件语句 (if, elseif, else)​

根据条件执行不同的代码块。

<?php
$grade = 75;

if ($grade >= 90) {
    echo "Grade: A";
} elseif ($grade >= 80) {
    echo "Grade: B";
} elseif ($grade >= 70) {
    echo "Grade: C";
} else {
    echo "Grade: D or F";
}
// Output: Grade: C
?>

5.2 switch 语句​

基于一个表达式的值匹配多个 case。

<?php
$day = "Monday";

switch ($day) {
    case "Monday":
        echo "Start of the work week.";
        break; // Important! Prevents fall-through
    case "Friday":
        echo "Almost weekend!";
        break;
    case "Saturday":
    case "Sunday": // Multiple cases can share a block
        echo "It's the weekend!";
        break;
    default:
        echo "It's a regular weekday.";
}
// Output: Start of the work week.
?>

5.3 循环语句 (for, while, do...while, foreach)​

  • for: 固定次数循环。
  • while: 条件为真时循环。
  • do...while: 先执行一次，然后条件为真时循环。
  • foreach: 遍历数组或对象的每个元素。
<?php
// for loop
echo "For Loop: ";
for ($i = 0; $i < 3; $i++) {
    echo $i . " "; // Output: 0 1 2
}
echo "<br>";

// while loop
echo "While Loop: ";
$j = 0;
while ($j < 3) {
    echo $j . " "; // Output: 0 1 2
    $j++;
}
echo "<br>";

// do...while loop
echo "Do...While Loop: ";
$k = 0;
do {
    echo $k . " "; // Output: 0 1 2
    $k++;
} while ($k < 3);
echo "<br>";

// foreach loop (for arrays)
echo "Foreach Loop (Array Values): ";
$colors = ["red", "green", "blue"];
foreach ($colors as $color) {
    echo $color . " "; // Output: red green blue
}
echo "<br>";

echo "Foreach Loop (Array Keys & Values): ";
$person = ["name" => "Eve", "age" => 25];
foreach ($person as $key => $value) {
    echo $key . ": " . $value . " | "; // Output: name: Eve | age: 25 |
}
echo "<br>";
?>

5.4 break 和 continue​

  • break: 跳出当前循环 (或 switch)。
  • continue: 跳过当前循环的剩余部分，进入下一次迭代。
<?php
echo "Break/Continue Example: ";
for ($i = 0; $i < 5; $i++) {
    if ($i === 3) {
        break; // Exit loop when $i is 3
    }
    if ($i === 1) {
        continue; // Skip iteration when $i is 1
    }
    echo $i . " "; // Output: 0 2
}
?>

5.5 include, require, include_once, require_once​

用于包含并执行其他 PHP 文件。

  • include: 如果文件不存在，产生警告 (Warning) 并继续执行脚本。
  • require: 如果文件不存在，产生致命错误 (Fatal Error) 并停止执行脚本。
  • include_once, require_once: 功能同上，但会检查文件是否已被包含过，如果已包含则不再包含。这是推荐的方式，以避免函数或类重复定义。
<?php
// Assume 'header.php' contains: <?php echo "<h1>Header Content</h1>"; ?>
// Assume 'config.php' contains: <?php define("DB_NAME", "mydatabase"); ?>

// include_once 'header.php'; // Include header only once
// require_once 'config.php'; // Include config only once, critical for script

// echo "Database name is: " . DB_NAME;

// Example using include (if 'nonexistent.php' doesn't exist):
// include 'nonexistent.php'; // Generates Warning, script continues
// echo "This line will still execute after include warning.";

// Example using require (if 'nonexistent.php' doesn't exist):
// require 'nonexistent.php'; // Generates Fatal Error, script stops
// echo "This line will NOT execute after require fatal error.";
?>

6. 函数 (Functions)​

6.1 定义与调用​

使用 function 关键字定义函数。

<?php
// Define a function
function greetUser($name) {
    echo "Hello, " . $name . "!";
}

// Call the function
greetUser("Alice"); // Output: Hello, Alice!
echo "<br>";

// Function with return value
function addNumbers($a, $b) {
    $sum = $a + $b;
    return $sum;
    // echo "This won't be executed"; // Code after return is not executed
}

$result = addNumbers(5, 7);
echo "5 + 7 = " . $result; // Output: 5 + 7 = 12
?>

6.2 函数参数与返回值类型声明 (PHP 7+)​

可以为参数和返回值指定类型（Type Hinting）。在严格模式下 (declare(strict_types=1);) 会强制类型匹配。

<?php
declare(strict_types=1); // Enable strict types mode for this file

// Function with type hints for parameters and return value
function multiply(float $a, float $b) : float {
    return $a * $b;
}

$product = multiply(3.5, 2.0);
echo "Product: " . $product; // Output: Product: 7
echo "<br>";

// $product = multiply("3.5", 2); // Fatal error in strict mode (string != float)
// In non-strict mode, PHP might try to convert "3.5" to float

function welcome(string $name, ?string $title = null) : string { // ?string allows NULL
    if ($title) {
        return "Welcome, " . $title . " " . $name;
    }
    return "Welcome, " . $name;
}

echo welcome("Bob"); // Output: Welcome, Bob
echo "<br>";
echo welcome("Charlie", "Mr."); // Output: Welcome, Mr. Charlie
echo "<br>";
echo welcome("Diana", null); // Output: Welcome, Diana
?>

6.3 变量作用域​

  • 局部作用域: 在函数内部定义的变量默认为局部变量，仅在函数内部可用。
  • 全局作用域: 在函数外部定义的变量为全局变量。要在函数内部访问全局变量，需使用 global 关键字或 $GLOBALS 超全局数组。
  • 静态作用域: 使用 static 关键字在函数内部声明的变量，在函数调用结束后其值会保留，下次调用时仍然存在。
<?php
$globalVar = "I am global";

function testScope() {
    $localVar = "I am local";
    echo $localVar; // OK
    echo "<br>";

    // Access global variable method 1: global keyword
    global $globalVar;
    echo $globalVar; // OK
    echo "<br>";

    // Access global variable method 2: $GLOBALS array
    echo $GLOBALS['globalVar']; // OK
    echo "<br>";
}

testScope();
// echo $localVar; // Error: Undefined variable $localVar (outside its scope)
echo $globalVar; // OK: Accessing global variable outside function
echo "<br>";

// Static variable example
function staticCounter() {
    static $count = 0; // Initialized only on first call
    $count++;
    echo $count . " ";
}

staticCounter(); // 1
staticCounter(); // 2
staticCounter(); // 3
?>

6.4 可变函数 (Variable Functions)​

将函数名存储在变量中，然后通过变量名加括号 () 来调用该函数。

<?php
function sayHello() {
    echo "Hello!";
}

$funcName = "sayHello";
$funcName(); // Calls sayHello(), Output: Hello!
?>

6.5 匿名函数 (Anonymous Functions) / 闭包 (Closures)​

没有名称的函数，通常赋值给变量或作为回调函数传递。可以从父作用域继承变量 (使用 use 关键字)。

<?php
// Assign anonymous function to a variable
$add = function($a, $b) {
    return $a + $b;
};
echo $add(3, 4); // Output: 7
echo "<br>";

// Closure using 'use' to capture variable from parent scope
$message = "World";
$greet = function($greeting) use ($message) {
    echo $greeting . ", " . $message . "!";
};

$greet("Hello"); // Output: Hello, World!
echo "<br>";

// Example as a callback for array_map
$numbers = [1, 2, 3, 4];
$squared = array_map(function($n) {
    return $n * $n;
}, $numbers);

print_r($squared); // Output: Array ( [0] => 1 [1] => 4 [2] => 9 [3] => 16 )
?>

6.6 箭头函数 (Arrow Functions - PHP 7.4+)​

匿名函数的简洁语法，特别适用于简单的回调。自动捕获外部作用域变量，无需 use。

<?php
// Arrow function equivalent of the $add example above
$addArrow = fn($a, $b) => $a + $b;
echo $addArrow(10, 5); // Output: 15
echo "<br>";

// Arrow function equivalent of the array_map example
$numbers = [1, 2, 3, 4];
$cubed = array_map(fn($n) => $n ** 3, $numbers);

print_r($cubed); // Output: Array ( [0] => 1 [1] => 8 [2] => 27 [3] => 64 )
?>

7. 数组 (Arrays)​

PHP 中的数组实际上是有序映射 (Ordered Map)，可以将值与特定的键关联起来。

7.1 类型​

  • 索引数组 (Indexed Arrays): 键是整数，通常从 0 开始自动索引。
  • 关联数组 (Associative Arrays): 键是字符串。
  • 多维数组 (Multidimensional Arrays): 数组包含其他数组。
<?php
// Indexed Array
$indexed = [10, 20, 30]; // Short syntax (PHP 5.4+)
// $indexed = array(10, 20, 30); // Old syntax
echo $indexed[1]; // Output: 20
echo "<br>";

// Associative Array
$assoc = [
    "name" => "Alice",
    "age" => 28,
    "city" => "New York"
];
echo $assoc["name"]; // Output: Alice
echo "<br>";

// Adding elements
$indexed[] = 40; // Adds 40 at the next available index (3)
$assoc["country"] = "USA"; // Adds a new key-value pair

print_r($indexed); // Array ( [0] => 10 [1] => 20 [2] => 30 [3] => 40 )
echo "<br>";
print_r($assoc); // Array ( [name] => Alice [age] => 28 [city] => New York [country] => USA )
echo "<br>";

// Multidimensional Array
$matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
];
echo $matrix[1][1]; // Output: 5 (Row 1, Column 1 - 0-indexed)
?>

7.2 常用数组函数​

PHP 提供了大量处理数组的内置函数。

  • count() 或 sizeof(): 返回数组元素个数。
  • is_array(): 检查变量是否是数组。
  • in_array(): 检查值是否存在于数组中。
  • array_key_exists() 或 isset(): 检查键是否存在于数组中 (isset 也检查值是否为 null)。
  • array_keys(): 返回数组的所有键。
  • array_values(): 返回数组的所有值。
  • array_push() / array_pop(): 在数组末尾添加/移除元素。
  • array_unshift() / array_shift(): 在数组开头添加/移除元素。
  • array_merge(): 合并一个或多个数组。
  • array_slice(): 提取数组的一部分。
  • sort(), rsort(), asort(), arsort(), ksort(), krsort(): 对数组进行不同方式的排序。
  • array_map(): 对数组的每个元素应用回调函数。
  • array_filter(): 使用回调函数过滤数组元素。
  • array_reduce(): 使用回调函数将数组迭代为单个值。
<?php
$myArray = ["a" => 1, "b" => 2, "c" => 3, "d" => 2];

echo "Count: " . count($myArray); // Count: 4
echo "<br>";

var_dump(in_array(2, $myArray)); // bool(true)
echo "<br>";
var_dump(array_key_exists("c", $myArray)); // bool(true)
echo "<br>";

print_r(array_keys($myArray));   // Array ( [0] => a [1] => b [2] => c [3] => d )
echo "<br>";
print_r(array_values($myArray)); // Array ( [0] => 1 [1] => 2 [2] => 3 [3] => 2 )
echo "<br>";

// Example: array_map
$numbers = [1, 2, 3];
$doubled = array_map(fn($n) => $n * 2, $numbers);
print_r($doubled); // Array ( [0] => 2 [1] => 4 [2] => 6 )
echo "<br>";

// Example: array_filter
$evenNumbers = array_filter($numbers, fn($n) => $n % 2 == 0);
print_r($evenNumbers); // Array ( [1] => 2 ) (Keys are preserved)
echo "<br>";

// Example: array_reduce
$sum = array_reduce($numbers, fn($carry, $item) => $carry + $item, 0); // 0 is initial carry
echo "Sum: " . $sum; // Sum: 6
?>

8. 面向对象编程 (OOP)​

PHP 具有完整的面向对象特性。

8.1 类与对象​

  • 类 (Class): 定义对象的蓝图（属性和方法）。
  • 对象 (Object): 类的实例。
<?php
// Define a class
class Car {
    // Properties (member variables) - Type hinting PHP 7.4+
    public string $make;
    public string $model;
    private int $year; // Private property

    public function __construct(string $make, string $model, int $year) {
        $this->make = $make; // $this refers to the current object

    }

    // Method (member function)
    public function getInfo(): string {
        return $this->make . " " . $this->model . " (" . $this->year . ")";

    public function setYear(int $year): void {

        } else {
            throw new InvalidArgumentException("Invalid year provided.");
        }
    }

    // Getter method for private property
    public function getYear(): int {
        return $this->year;
    }

    // Destructor method (called when object is destroyed or script ends)
    public function __destruct() {
        // echo "Car object destroyed: " . $this->make . " " . $this->model . "<br>";
    }
}

// Create objects (instances) of the Car class
$car1 = new Car("Toyota", "Camry", 2021);
$car2 = new Car("Honda", "Civic", 2022);

// Access public properties and methods

8.2 继承 (Inheritance)​

一个类（子类）可以继承另一个类（父类）的属性和方法。使用 extends 关键字。使用 parent:: 访问父类的方法或属性。

<?php
class Vehicle {
    public string $color;

    public function __construct(string $color = 'white') {
        $this->color = $color;
    }

    public function honk(): void {
        echo "Generic honk!";
    }
}

// Truck inherits from Vehicle
class Truck extends Vehicle {
    public int $payloadCapacity;

    public function __construct(string $color, int $capacity) {
        parent::__construct($color); // Call parent constructor
        $this->payloadCapacity = $capacity;
    }

    // Override parent method
    public function honk(): void {
        echo "Truck horn sound!";
    }

    public function getTruckInfo(): string {
        return "Color: " . $this->color . ", Capacity: " . $this->payloadCapacity . "kg";
    }
}

$myTruck = new Truck("Red", 5000);
echo $myTruck->getTruckInfo(); // Output: Color: Red, Capacity: 5000kg
echo "<br>";
$myTruck->honk(); // Output: Truck horn sound! (Overridden method)
echo "<br>";
// Accessing parent method explicitly (if needed and not overridden, or from within child)
// parent::honk(); // Can be used inside Truck methods
?>

8.3 访问修饰符 (Visibility)​

控制属性和方法的可见性：

  • public: 可以在任何地方访问。
  • protected: 只能在类自身及其子类中访问。
  • private: 只能在定义它的类自身中访问。
<?php
class MyClass {
    public $publicVar = "Public";
    protected $protectedVar = "Protected";
    private $privateVar = "Private";

    public function testAccess() {
        echo $this->publicVar;    // OK
        echo "<br>";
        echo $this->protectedVar; // OK
        echo "<br>";
        echo $this->privateVar;   // OK
        echo "<br>";
    }
}

class SubClass extends MyClass {
    public function testSubAccess() {
        echo $this->publicVar;    // OK
        echo "<br>";
        echo $this->protectedVar; // OK (can access protected from parent)
        echo "<br>";
        // echo $this->privateVar;   // Fatal error: Cannot access private property MyClass::$privateVar
    }
}

$obj = new MyClass();
echo $obj->publicVar; // OK
echo "<br>";
// echo $obj->protectedVar; // Fatal error
// echo $obj->privateVar; // Fatal error
$obj->testAccess(); // Accesses all internally

echo "<hr>";

$subObj = new SubClass();
echo $subObj->publicVar; // OK
echo "<br>";
$subObj->testSubAccess(); // Accesses public and protected
?>

8.4 静态属性与方法 (static)​

属于类本身，而不是类的实例。通过类名加 :: (范围解析操作符) 访问。

<?php
class Counter {
    public static int $count = 0; // Static property

    public function __construct() {
        self::$count++; // Access static property using self:: inside the class
    }

    public static function getCount(): int { // Static method
        return self::$count;
    }
}

$c1 = new Counter();
$c2 = new Counter();

echo Counter::$count; // Access static property using ClassName:: (Output: 2)
echo "<br>";
echo Counter::getCount(); // Call static method (Output: 2)
?>

8.5 抽象类与方法 (abstract)​

  • 抽象类: 不能被实例化，只能被继承。可以包含抽象方法和普通方法。
  • 抽象方法: 只有声明，没有具体实现。子类必须实现父类所有的抽象方法。
<?php
abstract class AbstractShape {
    abstract public function getArea(): float; // Abstract method declaration

    public function getDescription(): string { // Regular method
        return "This is a shape.";
    }
}

class Circle extends AbstractShape {
    private float $radius;

    public function __construct(float $radius) {
        $this->radius = $radius;
    }

    // Must implement the abstract method
    public function getArea(): float {
        return pi() * $this->radius * $this->radius;
    }
}

class Rectangle extends AbstractShape {
    private float $width;
    private float $height;

     public function __construct(float $width, float $height) {
        $this->width = $width;
        $this->height = $height;
    }

    public function getArea(): float {
        return $this->width * $this->height;
    }
}

// $shape = new AbstractShape(); // Fatal error: Cannot instantiate abstract class

$circle = new Circle(5);
echo $circle->getDescription() . " Area: " . $circle->getArea(); // This is a shape. Area: 78.539...
echo "<br>";
$rectangle = new Rectangle(4, 6);
echo $rectangle->getDescription() . " Area: " . $rectangle->getArea(); // This is a shape. Area: 24
?>

8.6 接口 (interface)​

定义类必须实现的方法契约，但接口本身不提供实现。类可以实现多个接口 (使用 implements)。

<?php
interface Loggable {
    public function log(string $message): void; // Interface methods are implicitly public and abstract
}

interface Editable {
    public function edit(string $content): bool;
}

// Class implementing multiple interfaces
class Document implements Loggable, Editable {
    private string $content = '';

    public function log(string $message): void {
        echo "[LOG] Document: " . $message . "<br>";
    }

    public function edit(string $content): bool {
        $this->content = $content;
        $this->log("Content updated.");
        return true;
    }

    public function getContent(): string {
        return $this->content;
    }
}

$doc = new Document();
$doc->edit("This is the new document content.");
echo "Document Content: " . $doc->getContent();
// Output:
// [LOG] Document: Content updated.
// Document Content: This is the new document content.
?>

8.7 Trait (PHP 5.4+)​

一种代码复用机制，用于在类之间共享方法实现，解决单继承的限制。使用 trait 关键字定义，use 关键字在类中使用。

<?php
trait LoggerTrait {
    public function logMessage(string $level, string $message): void {
        echo "[" . strtoupper($level) . "] " . $message . "<br>";
    }
}

trait UtilityTrait {
    public function generateId(): string {
        return uniqid();
    }
}

class User {
    use LoggerTrait; // Use the Logger trait
    use UtilityTrait; // Use the Utility trait

    public string $name;
    public string $id;

    public function __construct(string $name) {
        $this->name = $name;
        $this->id = $this->generateId(); // Method from UtilityTrait
        $this->logMessage('info', "User created: {$this->name} (ID: {$this->id})"); // Method from LoggerTrait
    }
}

class Order {
    use LoggerTrait;

    public int $orderId;

    public function __construct(int $id) {
        $this->orderId = $id;
        $this->logMessage('info', "Order created: #{$this->orderId}");
    }
}

$user = new User("Frank");
$order = new Order(123);
// Output:
// [INFO] User created: Frank (ID: <unique_id>)
// [INFO] Order created: #123
?>

9. 超全局变量 (Superglobals)​

PHP 提供了一些预定义的全局变量，称为超全局变量，可以在脚本的任何作用域中直接访问，无需 global 关键字。

  • $GLOBALS: 包含所有全局变量的关联数组。
  • $_SERVER: 包含服务器和执行环境信息（如请求头、路径、脚本位置）。
  • $_GET: 包含通过 HTTP GET 方法传递给脚本的变量（URL 查询参数）。
  • $_POST: 包含通过 HTTP POST 方法传递给脚本的变量（通常来自表单提交）。
  • $_REQUEST: 包含 $_GET, $_POST, 和 $_COOKIE 的内容（顺序和可用性取决于 request_order 配置）。谨慎使用，优先使用 $_GET 或 $_POST。
  • $_FILES: 包含通过 HTTP POST 文件上传方式传递给脚本的项目。
  • $_COOKIE: 包含通过 HTTP Cookies 传递给脚本的变量。
  • $_SESSION: 包含会话变量。需要先启动会话 (session_start())。
  • $_ENV: 包含通过环境方法传递给脚本的变量。
<?php
// Example usage (run this script via a web server)

echo "Script Name: " . ($_SERVER['SCRIPT_NAME'] ?? 'N/A') . "<br>";
echo "Request Method: " . ($_SERVER['REQUEST_METHOD'] ?? 'N/A') . "<br>";

// Accessing GET parameter (e.g., script.php?name=Alice)
$name = $_GET['name'] ?? 'Guest';
echo "Name from GET: " . htmlspecialchars($name) . "<br>"; // Use htmlspecialchars for security!

// Accessing POST parameter (from a form submission)
$email = $_POST['email'] ?? 'Not provided';
echo "Email from POST: " . htmlspecialchars($email) . "<br>";

// Accessing Cookie (assuming a cookie named 'user_preference' exists)
$preference = $_COOKIE['user_preference'] ?? 'Default';
echo "User Preference Cookie: " . htmlspecialchars($preference) . "<br>";

// Session example needs session_start() at the top of the script
// session_start();
// $_SESSION['views'] = ($_SESSION['views'] ?? 0) + 1;
// echo "Page views this session: " . $_SESSION['views'] . "<br>";
?>

13. 文件处理​

}

14. 数据库交互 (PDO)​

PDO (PHP Data Objects) 提供了一个统一的接口来访问多种数据库（MySQL, PostgreSQL, SQLite 等），是现代 PHP 中推荐的数据库交互方式。它支持预处理语句（Prepared Statements）以防止 SQL 注入。

<?php
// --- Database Configuration (Replace with your actual details) ---
$db_host = "localhost"; // Or your DB host IP/domain
$db_name = "test_database";
$db_user = "root"; // Replace with your DB username
$db_pass = "";     // Replace with your DB password
$charset = 'utf8mb4';

// --- PDO Connection String (DSN) ---
$dsn = "mysql:host=$db_host;dbname=$db_name;charset=$charset";

// --- PDO Options ---
$options = [
    PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION, // Throw exceptions on errors
    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,     // Fetch results as associative arrays
    PDO::ATTR_EMULATE_PREPARES   => false,                // Use native prepared statements
];

// --- Connect to Database ---
try {
     $pdo = new PDO($dsn, $db_user, $db_pass, $options);
     echo "Database connection successful!<br>";

     // --- Example: Insert Data (using Prepared Statement) ---
     $sql_insert = "INSERT INTO users (name, email) VALUES (?, ?)"; // Placeholders ?
     $stmt_insert = $pdo->prepare($sql_insert);
     // Execute with data array - protects against SQL injection
     // $stmt_insert->execute(['Alice Wonderland', 'alice@example.com']);
     // $stmt_insert->execute(['Bob The Builder', 'bob@example.com']);
     // echo "Data inserted successfully.<br>";


     // --- Example: Select Data (using Prepared Statement) ---
     $user_id = 1; // Example ID to fetch
     $sql_select = "SELECT id, name, email FROM users WHERE id = :id"; // Named placeholder :id
     $stmt_select = $pdo->prepare($sql_select);
     // Bind named placeholder
     $stmt_select->bindParam(':id', $user_id, PDO::PARAM_INT);
     $stmt_select->execute();

     // Fetch a single row
     $user = $stmt_select->fetch(); // Default is PDO::FETCH_ASSOC from options

     if ($user) {
         echo "Fetched User:<pre>";
         print_r($user);
         echo "</pre>";
     } else {
         echo "User with ID " . $user_id . " not found.<br>";
     }


     // --- Example: Select Multiple Rows ---
     $sql_select_all = "SELECT id, name FROM users ORDER BY name";
     // No user input, so prepare/execute can be simplified (though prepare is still good practice)
     $stmt_all = $pdo->query($sql_select_all); // Direct query for simple selects

     echo "All Users:<br><ul>";
     while ($row = $stmt_all->fetch()) { // Fetch rows one by one
         echo "<li>ID: " . htmlspecialchars((string)$row['id']) . " - Name: " . htmlspecialchars($row['name']) . "</li>";
     }
     echo "</ul>";


} catch (PDOException $e) {
     // Handle connection errors
     echo "Database Connection Error: " . $e->getMessage() . "<br>";
     // In a real app, log the error and show a generic message to the user
     // throw new PDOException($e->getMessage(), (int)$e->getCode());
     die("Could not connect to the database. Please try again later.");
}

// Close connection (optional, PHP usually handles this at script end)
// $pdo = null;
?>

// Using imported class
$conn = new Connection();
$conn->connect(); // Output: Connecting from MyApp\Database\Connection...

// Using aliased class
$logger = new UtilsLogger();
$logger->log("Application started."); // Output: [MyApp Utils Logger] Application started.

// Using imported function
helperFunc(); // Output: Helper function from MyApp\Utils called.

// Using imported constant
echo "Utils Version: " . UTILS_VERSION; // Output: Utils Version: 1.0
?>

16. Composer​

PHP 的依赖管理工具。用于声明项目依赖的库，并管理它们的安装和自动加载。虽然 Composer 本身不是 PHP 语言特性，但它是现代 PHP 开发的核心工具。

  1. composer.json: 定义项目元数据和依赖项。
  2. composer install: 根据 composer.json (或 composer.lock) 安装依赖项到 vendor 目录。
  3. composer update: 更新依赖项到最新允许的版本，并更新 composer.lock。
  4. Autoloading: Composer 生成 vendor/autoload.php 文件，只需在项目中 require 这一个文件，即可自动加载所有通过 Composer 安装的库以及你自己的符合 PSR-4 规范的代码。
// Example composer.json
{
  "name": "my-vendor/my-project",
  "description": "A sample project.",
  "require": {
    "php": ">=8.0", // Require PHP version 8.0 or higher
    "monolog/monolog": "^2.0" // Require Monolog library version 2.x
  },
  "autoload": {
    "psr-4": {
      "MyApp\\": "src/" // Map MyApp namespace to src/ directory
    }
  }
}
<?php
// index.php (after running 'composer install')

// Include Composer's autoloader
require_once __DIR__ . '/vendor/autoload.php';

use Monolog\Logger;
use Monolog\Handler\StreamHandler;
use MyApp\MyClass; // Assuming you have src/MyClass.php with namespace MyApp

// Use a class from a Composer package
$log = new Logger('main');
$log->pushHandler(new StreamHandler('app.log', Logger::WARNING));
$log->warning('This is a warning message.');

// Use your own class via PSR-4 autoloading
// $myApp = new MyClass();
// $myApp->doSomething();

echo "Composer example finished. Check app.log for warning.";
?>

17. JSON 处理​

PHP 内置函数用于处理 JSON 数据，这在 Web API 交互中非常常见。

  • json_encode(): 将 PHP 数组或对象转换为 JSON 字符串。
  • json_decode(): 将 JSON 字符串解析为 PHP 数组或对象。
<?php
// --- Encoding PHP array to JSON ---
$dataArray = [
    "name" => "Gadget",
    "version" => 1.5,
    "features" => ["featureA", "featureB"],
    "enabled" => true
];

$jsonString = json_encode($dataArray, JSON_PRETTY_PRINT | JSON_UNESCAPED_SLASHES);
echo "Encoded JSON:<pre>" . htmlspecialchars($jsonString) . "</pre>";
/* Output:
Encoded JSON:
{
    "name": "Gadget",
    "version": 1.5,
    "features": [
        "featureA",
        "featureB"
    ],
    "enabled": true
}
*/


// --- Decoding JSON string to PHP ---
$receivedJson = '{ "id": 123, "item": "Widget", "in_stock": false, "location": null }';

// Decode to PHP object (default)
$phpObject = json_decode($receivedJson);
echo "Decoded Object:<pre>";
var_dump($phpObject);
echo "</pre>";
echo "Item from object: " . htmlspecialchars($phpObject->item) . "<br>"; // Access using ->

// Decode to PHP associative array
$phpArray = json_decode($receivedJson, true); // Pass true as the second argument
echo "Decoded Array:<pre>";
var_dump($phpArray);
echo "</pre>";
echo "Item from array: " . htmlspecialchars($phpArray['item']) . "<br>"; // Access using ['key']

// Handling JSON errors (PHP 5.3+)
json_decode("{ invalid json "); // Malformed JSON
$errorCode = json_last_error();
if ($errorCode !== JSON_ERROR_NONE) {
    echo "JSON Decode Error: " . json_last_error_msg() . " (Code: " . $errorCode . ")<br>";
}
?>

18. 基本安全考量​

  • 输入验证: 永远不要信任用户输入。使用 filter_var(), 正则表达式等验证数据格式、类型、范围。
  • 输出转义: 在 HTML 中显示用户提供的数据时，使用 htmlspecialchars() 防止 XSS (跨站脚本攻击)。
  • SQL 注入防护: 使用预处理语句 (Prepared Statements) 和参数绑定 (如 PDO 示例所示)。
  • 密码哈希: 存储密码时，使用 password_hash() 生成强哈希，使用 password_verify() 进行验证。不要存储明文密码或使用弱哈希算法 (如 MD5, SHA1)。
  • 会话安全: 使用 session_regenerate_id() 防止会话固定攻击，配置安全的 session cookie (httponly, secure)。
  • 文件上传安全: 验证文件类型、大小，不要使用用户提供的文件名直接存储文件，将上传目录置于 Web 根目录之外。
<?php
// --- Output Escaping ---
$userInput = '<script>alert("XSS Attack!");</script>';
// Incorrect (Vulnerable): echo $userInput;
// Correct:
echo "Escaped Output: " . htmlspecialchars($userInput, ENT_QUOTES, 'UTF-8') . "<br>";


// --- Input Validation ---
$userAge = $_POST['age'] ?? 'abc';
if (filter_var($userAge, FILTER_VALIDATE_INT, ["options" => ["min_range" => 0, "max_range" => 120]])) {
    echo "Valid age: " . $userAge . "<br>";
} else {
    echo "Invalid age provided: " . htmlspecialchars($userAge) . "<br>";
}


// --- Password Hashing ---
$plainPassword = "mySecretPassword123";
$hashedPassword = password_hash($plainPassword, PASSWORD_DEFAULT); // Use default strong algorithm

echo "Hashed Password: " . $hashedPassword . "<br>";

// --- Password Verification ---
$loginAttempt = "mySecretPassword123";
if (password_verify($loginAttempt, $hashedPassword)) {
    echo "Password is valid!<br>";
} else {
    echo "Invalid password!<br>";
}
?>
