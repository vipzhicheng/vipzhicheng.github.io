核心知识点

1. 基础概念​

1.1 JavaScript 简介​

一种高级、解释型编程语言，主要用于 Web 开发，支持动态交互。

1.2 运行环境​

可在浏览器（如 V8 引擎）和服务器端（如 Node.js）运行。

1.3 变量与常量​

使用 var、let、const 声明变量，分别有不同作用域和特性。

1.4 数据类型​

包括原始类型（Number、String、Boolean、Null、Undefined、Symbol、BigInt）和对象类型。

1.5 类型转换​

隐式（如 "1" + 1）和显式（如 parseInt()）类型转换。

1.6 作用域​

变量的可访问范围，包括全局、函数和块级作用域。

1.7 提升（Hoisting）​

变量和函数声明在执行前提升到作用域顶部。

2. 运算符与表达式​

2.1 算术运算符​

加（+）、减（-）、乘（*）、除（/）、取模（%）等。

2.2 比较运算符​

等于（==）、严格等于（===）、大于（>）、小于（<）等。

2.3 逻辑运算符​

与（&&）、或（||）、非（!）用于条件判断。

2.4 赋值运算符​

基本赋值（=）及复合赋值（如 +=、-=）。

2.5 位运算符​

处理二进制位，如与（&）、或（|）、异或（^）。

2.6 三元运算符​

条件表达式：condition ? value1 : value2。

3. 控制流​

3.1 条件语句​

使用 if、else if、else 根据条件执行代码。

3.2 开关语句​

switch 用于多条件分支选择。

3.3 循环语句​

for、while、do...while 用于重复执行代码。

3.4 异常处理​

try、catch、finally 和 throw 处理运行时错误。

4. 函数​

4.1 函数定义​

使用 function 或箭头函数（=>）定义可重用代码块。

4.2 参数与返回值​

函数接受参数并通过 return 返回值。

4.3 默认参数​

为参数设置默认值，如 function fn(x = 1) {}。

4.4 剩余参数（Rest Parameters）​

使用 ... 收集多个参数，如 function fn(...args) {}。

4.5 闭包​

函数记住外部作用域变量。

4.6 高阶函数​

接受或返回函数的函数。

5. 对象与数据结构​

5.1 对象基础​

键值对集合，使用 . 或 [] 访问属性。

5.2 对象方法​

对象中的函数属性。

5.3 原型（Prototype）​

对象继承的基础，通过原型链共享属性和方法。

5.4 数组​

有序列表，支持索引访问。

5.5 Map 与 Set​

键值对（Map）和唯一值集合（Set）数据结构。

5.6 JSON​

JavaScript 对象表示法，用于数据交换。

6. 面向对象编程（OOP）​

6.1 构造函数​

使用 new 创建对象实例的函数。

6.2 类（Class）​

ES6 语法糖，用于定义对象模板，如 class MyClass {}。

6.3 继承​

通过 extends 实现类复用。

6.4 封装​

使用闭包或类隐藏实现细节。

6.5 多态​

不同对象对同一方法的不同实现。

7. 异步编程​

7.1 回调函数​

将函数作为参数传递处理异步操作。

7.2 Promise​

表示异步操作结果的对象，支持 .then() 和 .catch()。

7.3 Async/Await​

基于 Promise 的语法糖，使异步代码更简洁。

7.4 事件循环（Event Loop）​

单线程模型中处理异步任务的机制。

7.5 定时器​

setTimeout 和 setInterval 用于延迟或定时执行。

8. DOM 操作​

8.1 DOM 简介​

文档对象模型，表示 HTML 结构。

8.2 选择元素​

使用 querySelector、getElementById 获取 DOM 节点。

8.3 修改 DOM​

更改元素内容、属性或样式。

8.4 事件监听​

使用 addEventListener 响应用户交互。

9. 模块化​

9.1 CommonJS​

Node.js 模块系统，使用 require 和 module.exports。

9.2 ES Modules​

现代标准，使用 import 和 export。

9.3 动态导入​

使用 import() 按需加载模块。

10. 现代特性（ES6+）​

10.1 解构赋值​

从数组或对象提取值，如 [a, b] = [1, 2]。

10.2 模板字面量​

使用反引号创建字符串，如 Hello ${name}。

10.3 扩展运算符（Spread Operator）​

使用 ... 展开数组或对象。

10.4 可选链（Optional Chaining）​

使用 ?. 安全访问嵌套属性，如 obj?.prop。

10.5 空值合并运算符（Nullish Coalescing）​

使用 ?? 处理 null 或 undefined。

10.6 Symbol​

创建唯一标识符。

10.7 BigInt​

处理任意精度整数，如 123n。

11. 函数式编程​

11.1 纯函数​

相同输入始终返回相同输出，无副作用。

11.2 不可变性​

避免直接修改数据。

11.3 数组方法​

map、filter、reduce 用于函数式操作。

12. 错误与调试​

12.1 错误类型​

SyntaxError、ReferenceError、TypeError 等。

12.2 调试工具​

浏览器开发者工具用于断点和日志。

12.3 日志记录​

使用 console.log、console.error 输出信息。

13. 性能优化​

13.1 防抖与节流​

限制函数调用频率。

13.2 内存管理​

避免内存泄漏，理解垃圾回收。

13.3 代码分割​

按需加载代码。

14. 浏览器与网络​

14.1 BOM（浏览器对象模型）​

操作浏览器窗口，如 window、location。

14.2 AJAX​

使用 fetch 或 XMLHttpRequest 进行异步请求。

14.3 Web Storage​

localStorage 和 sessionStorage 用于客户端存储。

14.4 WebSocket​

实现实时双向通信。

15. Node.js 相关​

15.1 核心模块​

如 fs（文件系统）、http（服务器）。

15.2 NPM​

包管理工具。

15.3 事件驱动​

使用事件循环处理异步任务。

16. 测试与工具​

16.1 单元测试​

使用 Jest、Mocha 测试代码。

16.2 代码格式化​

Prettier、StandardJS 规范化代码。

16.3 构建工具​

Webpack、Vite 用于打包。

17. 安全​

17.1 XSS（跨站脚本攻击）​

防止恶意代码注入。

17.2 CSRF（跨站请求伪造）​

保护表单提交安全。

17.3 输入验证​

确保用户输入安全有效。
