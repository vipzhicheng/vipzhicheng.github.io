开发相关​

  • SVGR 将 SVG 转为 React 组件。
  • Svg.js 是一个轻量级 JavaScript 库，适合动态操作 SVG，安装简单，支持 npm。
  • Snap.svg 提供丰富的动画库和事件处理，适合交互式 SVG 开发，基于 Apache 2 许可证。
  • D3.js 是数据可视化库，广泛用于生成动态 SVG 图表，适合复杂交互。
  • SVGO 优化工具
  • Two 是一个轻量级的 SVG 图形库，支持动画和交互。
  • GSAP 动画库，商用收费。
