Logseq Task Management 插件发布

2022年1月17日 · 阅读需 2 分钟

这是一个基于 Task Management 为 Logseq 创建任务管理的插件。

默认快捷键​

  • ctrl+1：切换为 TODO 任务。
  • ctrl+2：切换为 DOING 任务。
  • ctrl+3：切换为 DONE 任务。
  • ctrl+4：切换为 LATER 任务。
  • ctrl+5：切换为 NOW 任务。
  • ctrl+6：切换为 WAITING 任务。
  • ctrl+7：切换为 CANCELLED 任务。
  • ctrl+0：切换为非任务。

自定义​

你可能想要更改绑定顺序、重新映射动作或快捷键。你可以通过手动编辑插件配置文件（JSON 格式）来实现，该文件可以在插件页面的齿轮下拉菜单中找到。

默认配置如下：

{
  "disabled": false,
  "keyBindings": {
    "0": "ctrl+0",
    "1": "ctrl+1",
    "2": "ctrl+2",
    "3": "ctrl+3",
    "4": "ctrl+4",
    "5": "ctrl+5",
    "6": "ctrl+6",
    "7": "ctrl+7"
  },
  "tasks": [
    "TODO",
    "DOING",
    "DONE",
    "LATER",
    "NOW",
    "WAITING",
    "CANCELLED"
  ],
  "settingsVersion": "v1"
}

你可以调整任务的顺序，添加 Logseq 支持的新状态，更改键绑定，并不要忘记保存你的更改。注意：键 0 始终表示移除任务标签。因此，keyBindings 中的 1~6 依次映射到 tasks 数组。

以下是一个示例，非建议：

{
  "disabled": false,
  "keyBindings": {
    "0": "a a",
    "1": "a s",
    "2": "a d",
    "3": "a f",
    "4": "a w",
    "5": "a e",
    "6": "a r"
  },
  "tasks": [
    "LATER",
    "NOW",
    "WAITING",
    "TODO",
    "DOING",
    "DONE"
  ],
  "settingsVersion": "v1"
}

如何你对这个插件感兴趣，可以在 Logseq 插件市场搜索安装和使用。

Logseq Lock 插件发布

2021年11月16日 · 阅读需 2 分钟

这是一个利用 Logseq 安全存储账户和密码的解决方案。

功能​

  • 可以用密码锁定任何 Logseq 块。
  • 如果你记得住，可以用不同的密码分别锁定。
  • 锁定后的信息会变得简短且不可见，但仍然存在。
  • 为不同的锁设置不同的图标，增加趣味性。
  • 原始数据无法被恢复，只能通过解锁操作将其放置到系统剪贴板中。
